# Xanders-Crusader-Mod

Este mod proporciona todo con «hacer clic e instalar» para jugar con todas mis IA: observar sus batallas, combatir tú mismo o jugar con amigos en multijugador. Aquí tienes los ajustes adecuados para ello.

Puedes ver exactamente este paquete en mi canal de YouTube [Xander10alpha](https://www.youtube.com/@Xander10alpha).

¡Que te diviertas! Me encantará recibir tus comentarios, críticas y sugerencias.

## Atención

Para jugar tú mismo, desmarca «Varios → Activar el modo espectador».
