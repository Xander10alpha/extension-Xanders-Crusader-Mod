# Xanders-Crusader-Mod

Этот мод предоставляет всё по принципу «нажать и установить», чтобы играть со всеми моими ИИ: наблюдать их битвы, выходить на поле боя самому или играть с друзьями по сети. Здесь собраны подходящие для этого настройки.

Этот же пакет можно увидеть на моём YouTube-канале [Xander10alpha](https://www.youtube.com/@Xander10alpha).

Желаю приятной игры и буду рад отзывам, критике и предложениям!

## Внимание

Чтобы играть самому, снимите флажок «Разное → Активировать режим наблюдателя».
