# Xanders-Crusader-Mod

Ce mod fournit tout en « cliquer et installer » pour jouer avec toutes mes IA, que vous observiez leurs batailles, les affrontiez vous-même ou jouiez avec des amis en multijoueur. Il contient les réglages adaptés à ces usages.

Vous pouvez voir ce même pack sur ma chaîne YouTube [Xander10alpha](https://www.youtube.com/@Xander10alpha).

Amusez-vous bien ! Vos retours, critiques et suggestions sont les bienvenus.

## Attention

Pour jouer vous-même, décochez « Divers → Activer le mode spectateur ».
