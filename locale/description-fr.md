# Xanders-Crusader-Mod

Ce pack réunit les IA de Xander et des extensions de châteaux pour les batailles contre l'IA, en solo ou entre amis. Vous pouvez voir le pack sur la chaîne YouTube [Xander10alpha](https://www.youtube.com/@Xander10alpha).

Si vous voulez jouer vous-même, désactivez **Miscellaneous > Activate Spectator mode**.
